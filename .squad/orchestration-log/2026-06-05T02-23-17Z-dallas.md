## Key Implementation Details

`ensureEntityObjectTypeCode(logicalName)`:
1. Check if metadata already loaded in cache
2. If not, await `queryClient.fetchQuery()` for entities query
3. Return resolved numeric objecttypecode
4. Never returns undefined for valid entity names

This ensures solution-scoped creates always have metadata ready before `addToSolution()` is called.
